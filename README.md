# KEY//DODGE

실제 QWERTY 키보드를 전장으로 사용하는 스테이지형 리듬 회피 게임입니다. 별도 타이틀에서 시작해 스테이지를 선택하고, 알파벳 키로 해당 셀에 즉시 이동하며 정해진 공격 시퀀스를 돌파하세요.

## 게임 구성

- 게임 HUD와 분리된 TITLE 및 STAGE_SELECT 화면
- 초기 선택 없이 강조와 확정을 분리하는 스테이지 선택
- 처음부터 선택 가능한 STAGE 01~06과 물리 Q/W/E/R/T/Y 선택
- 스테이지별 오프닝 BPM과 플레이 중 감속·가속·러시 템포 변화
- 플레이 시작 전 오프닝 BPM에 맞춘 3→2→1 카운트다운
- 패턴에 따라 5–26키 사이에서 확장·축소되는 활성 키 존
- 축소 때 존 밖 플레이어를 F로 재집결한 뒤 한 박 경고
- `KeyboardEvent.code` 기반 물리 키 위치 입력
- 박자 기반 공격 예고와 키 셀 단위 충돌 판정
- HP 5, 피격 후 500ms 무적
- 스테이지별 12, 14, 16, 18, 21, 24개 고정 웨이브와 클리어 결과
- 하나만 빼고 전부 공격하는 `ONLY SAFE` 패턴
- 예고 중 해당 키를 직접 입력하면 HP를 1 회복하는 희귀 패턴
- 점수, 연속 회피, 재도전·스테이지 선택·조건부 다음 스테이지 결과 동선
- Web Audio 효과음과 음소거
- Escape 일시정지 및 탭 이탈 자동 일시정지
- 클릭/터치 키 이동과 반응형 화면

## 조작

| 입력 | 동작 |
|---|---|
| TITLE의 `Space` / `Enter` | STAGE_SELECT로 이동 |
| TITLE 시작 버튼 클릭 | STAGE_SELECT로 이동 |
| STAGE_SELECT의 물리 `Q` / `W` / `E` / `R` / `T` / `Y` 첫 입력 | STAGE 01~06 카드 강조 |
| 강조된 카드와 같은 `Q` / `W` / `E` / `R` / `T` / `Y` 두 번째 입력 | 해당 스테이지 확정 |
| STAGE_SELECT의 화살표 | 카드 강조 만들기 / 이동 |
| STAGE_SELECT의 `Enter` | 강조된 카드 확정, 무선택이면 무동작 |
| 스테이지 카드 첫 클릭 | 해당 카드 강조 |
| 강조된 같은 카드 두 번째 클릭 | 해당 스테이지 확정 |
| 플레이 중 `A`–`Z` | 활성 상태인 해당 키 셀로 즉시 이동 |
| 결과 화면의 `Space` / `Enter` | 강조된 기본 결과 동작 실행 |
| `Escape` | 일시정지 / 계속 |
| `0` | 소리 켜기 / 끄기 |

마지막으로 누른 유효 알파벳 키가 현재 위치입니다. 키를 계속 누를 필요는 없으며, 인접한 키로만 이동해야 하는 제한도 없습니다.

스테이지를 확정하면 즉시 공격이 시작되지 않습니다. 해당 스테이지의 오프닝 BPM 한 박마다 `3 → 2 → 1`을 표시한 뒤 플레이가 시작됩니다. 카운트다운 중 `Escape`를 누르거나 창 포커스를 잃으면 예약된 시작을 취소하고 무선택 STAGE_SELECT로 돌아갑니다.

플레이 도중 BPM은 고정되지 않습니다. 모든 스테이지가 `OPENING → EXPANSION/SPEED-UP → CONTRACTION/SLOWDOWN → LARGER/FASTER FINALE` 순서로 진행되며, HUD에서 현재 BPM·섹션·활성 키 수를 확인할 수 있습니다. 공격은 현재 활성 존 안에서만 발생하고 항상 안전 키를 남깁니다. 존 축소 때 현재 위치가 새 존 밖이면 F로 먼저 이동한 뒤 한 박 동안 `ZONE CONTRACT` 경고가 표시됩니다.

| 스테이지 | 선택 키 | 웨이브 | 오프닝 BPM | BPM 범위 | 활성 키 범위 |
|---|---:|---:|---:|---:|---:|
| STAGE 01 | Q | 12 | 92 | 82–110 | 5–11 |
| STAGE 02 | W | 14 | 100 | 88–122 | 8–15 |
| STAGE 03 | E | 16 | 108 | 94–132 | 10–19 |
| STAGE 04 | R | 18 | 116 | 102–142 | 12–22 |
| STAGE 05 | T | 21 | 124 | 108–150 | 15–25 |
| STAGE 06 | Y | 24 | 132 | 116–156 | 18–26 |

결과 화면의 `RETRY`는 같은 스테이지의 오프닝 BPM 카운트다운을 시작하고, `STAGE SELECT`는 무선택 선택 화면으로 돌아갑니다. `NEXT STAGE`는 STAGE 01~05를 클리어했을 때만 표시되며 다음 스테이지의 카운트다운을 시작합니다. 이때 `Space`/`Enter`의 기본 동작은 NEXT STAGE이며, 게임 오버 또는 STAGE 06 클리어에서는 RETRY가 기본 동작입니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm 11이 필요합니다.

```bash
pnpm install
pnpm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

pnpm run typecheck
