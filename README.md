# KEY//DODGE

실제 QWERTY 키보드를 전장으로 사용하는 스테이지형 리듬 회피 게임입니다. 별도 타이틀에서 시작해 스테이지를 선택하고, 알파벳 키로 해당 셀에 즉시 이동하며 정해진 공격 시퀀스를 돌파하세요.

플레이: [https://fiso-maker.github.io/keyboard-dodge/](https://fiso-maker.github.io/keyboard-dodge/)

## 게임 구성

- 게임 HUD와 분리된 TITLE 및 STAGE_SELECT 화면
- 스테이지 수·키 수·BPM 사양표를 덜어내고 시작 동작에 집중한 TITLE
- 초기 선택 없이 강조와 확정을 분리하는 스테이지 선택
- 처음부터 선택 가능한 STAGE 01~06과 물리 Q/W/E/R/T/Y 선택
- POLAR WHITE를 기본으로 제공하는 여섯 가지 시각 테마와 화면 내 설정
- 스테이지별 오프닝 BPM과 플레이 중 감속·가속·러시 템포 변화
- 키보드를 가리지 않는 작은 배지의 오프닝 BPM 3→2→1 카운트다운과 준비 이동
- 5웨이브 펄스에 따라 5–26키 사이에서 확장·축소되는 활성 키 존
- 직전 공격의 위험 키를 1.5박 `COLLAPSE WARNING` 뒤 없애는 인과형 축소
- 새 키를 1.25박 `RESTORE WARNING` 뒤 여는 확장
- `KeyboardEvent.code` 기반 물리 키 위치 입력
- 박자 기반 공격 예고와 키 셀 단위 충돌 판정
- HP 5, 피격 후 500ms 무적
- 스테이지별 52, 56, 60, 64, 68, 72개 웨이브와 약 113–116초 길이
- 하나만 빼고 전부 공격하는 `ONLY SAFE` 패턴
- 예고 중 해당 키를 직접 입력하면 HP를 1 회복하는 희귀 패턴
- 13웨이브마다 방향을 바꿔 3번 이어지는 `WAVE SURGE`
- 상단 계기판형 HUD, 일시적 연속 회피 피드백과 재도전·스테이지 선택·조건부 다음 스테이지 결과 동선
- 두 번째 구간부터 표시되는 `ACT n / 4`, 마지막 `FINAL SEQUENCE`와 스테이지별 식별색
- 스테이지별 로컬 시도·클리어·최고 기록과 S/A/B/C/D 런 등급
- 등급·레이팅·점수·최고 콤보·HP·웨이브와 신기록 배지를 보여주는 런 보고서
- 여섯 스테이지별 원본 절차형 Web Audio 스코어, 효과음과 음소거
- Escape 일시정지 및 탭 이탈 자동 일시정지
- 클릭/터치 키 이동과 반응형 화면

## 조작

| 입력 | 동작 |
|---|---|
| TITLE의 `Space` / `Enter` | STAGE_SELECT로 이동 |
| TITLE 시작 버튼 클릭 | STAGE_SELECT로 이동 |
| STAGE_SELECT의 물리 `Q` / `W` / `E` / `R` / `T` / `Y` 첫 입력 | 대응 카드를 덱 중앙으로 스크롤하고 전면 강조 |
| 강조된 카드와 같은 `Q` / `W` / `E` / `R` / `T` / `Y` 두 번째 입력 | 해당 스테이지 확정 |
| STAGE_SELECT의 화살표 | 가로 덱의 인접 카드로 강조·중앙 이동 |
| STAGE_SELECT의 `Enter` | 강조된 카드 확정, 무선택이면 무동작 |
| 스테이지 카드 첫 클릭 | 해당 카드를 중앙으로 스크롤하고 전면 강조 |
| 강조된 같은 카드 두 번째 클릭 | 해당 스테이지 확정 |
| COUNTDOWN 중 `A`–`Z` | 오프닝 활성 키 안에서 시작 위치 준비 |
| 플레이 중 `A`–`Z` | 활성 상태인 해당 키 셀로 즉시 이동 |
| 결과 화면의 `Space` / `Enter` | 강조된 기본 결과 동작 실행 |
| `Escape` | 일시정지 / 계속 |
| `0` | 소리 켜기 / 끄기 |

마지막으로 누른 유효 알파벳 키가 현재 위치입니다. 키를 계속 누를 필요는 없으며, 인접한 키로만 이동해야 하는 제한도 없습니다.

스테이지를 확정하면 즉시 공격이 시작되지 않습니다. 키보드 위의 작은 준비 배지에서 해당 스테이지의 오프닝 BPM 한 박마다 `3 → 2 → 1`을 표시한 뒤 플레이가 시작됩니다. 이 동안 오프닝 활성 키로 위치를 미리 정할 수 있지만 공격, 점수, 콤보, 웨이브와 플레이 타이머는 시작하지 않습니다. `Escape`를 누르거나 창 포커스를 잃으면 예약된 시작을 취소하고 무선택 STAGE_SELECT로 돌아갑니다.

플레이 도중 BPM은 고정되지 않습니다. 모든 스테이지가 `OPENING → EXPANSION/SPEED-UP → CONTRACTION/SLOWDOWN → LARGER/FASTER FINALE` 순서로 진행되며, HUD에서 현재 BPM·섹션·활성 키 수를 확인할 수 있습니다. 공격은 현재 활성 존 안에서만 발생하고 항상 안전 키를 남깁니다.

두 번째 구간부터 진행 영역에 `ACT n / 4`와 섹션명이 짧게 나타나고, 마지막 구간은 `FINAL SEQUENCE`로 강조됩니다. 진행선과 주요 강조색도 선택한 스테이지의 식별색을 사용해 약 2분의 런을 네 막으로 읽을 수 있게 합니다.

`WAVE SURGE`는 0부터 세는 `waveIndex 5`에서 처음 시작하고 이후 13웨이브마다 정확히 3번 이어집니다. 시퀀스마다 왼쪽→오른쪽과 오른쪽→왼쪽 방향을 번갈아 사용하며, 매 웨이브의 파도 대상은 그 순간의 활성 키 존에서 다시 계산되어 최소 2개의 안전 키를 남깁니다. 화면에는 방향 화살표, `1/3`–`3/3`, 현재 위치의 이동 필요 여부와 키보드 위 방향성 신호가 함께 표시됩니다.

배경 스코어는 제3자 녹음, 샘플 또는 기성 작곡을 사용하지 않고 브라우저 Web Audio로 실시간 합성합니다. 여섯 스테이지는 서로 다른 모티프를 가지며 4/4의 킥·펄스·하이햇·베이스·모티프 편곡이 현재 ACT, BPM과 강도를 따라 변합니다. 게임의 `performance.now()` 기반 시계가 공격과 충돌의 기준이고 음악은 게임 상태를 따라갈 뿐 판정을 진행시키지 않습니다. 카운트다운, 시작, 일시정지, 재개, 음소거와 결과 전환도 같은 오디오 수명주기에 연결됩니다.

STAGE_SELECT는 왼쪽에서 오른쪽으로 스크롤되는 카드 덱입니다. Q/W/E/R/T/Y나 화살표로 고른 카드는 중앙으로 이동하며 주변 카드보다 크게 앞으로 튀어나옵니다. 첫 입력은 강조만 하고 같은 키·카드의 두 번째 입력 또는 Enter로 확정합니다.

## 인터페이스 테마

`POLAR WHITE`가 기본 테마이며 `WARM WHITE`, `MONO SIGNAL`, `SIGNAL BLUE`, `AMBER OPS`, `IVORY LAB`까지 정확히 여섯 가지를 제공합니다. 설정의 각 버튼은 적용 전에도 테마별 배경·패널 형태·제목 서체·QWERT 키캡·5색 팔레트를 미리 보여줍니다. 테마 설정은 TITLE, STAGE_SELECT와 플레이 화면에서 열 수 있습니다. 플레이 중 설정을 열면 게임이 먼저 안전하게 일시정지하며, 설정을 닫은 뒤에는 직접 재개해야 합니다. 시작 박자와 준비 입력을 보호하기 위해 COUNTDOWN 중에는 테마 설정이 비활성화됩니다.

테마 전환은 배경·패널·타이포그래피·상태 색 같은 시각 요소만 바꿉니다. 타이머, 입력, 공격, BPM, 활성 키 존, HP, 점수, 콤보와 현재 게임 상태에는 영향을 주지 않습니다. STAGE_SELECT의 왼쪽→오른쪽 가로 스크롤·중앙 팝업 카드 덱도 모든 테마에서 그대로 유지됩니다.

플레이 핵심 정보는 상단 계기판형 HUD에서 스테이지·웨이브·점수·HP·현재 BPM·섹션·활성 키 수·진행도로 확인합니다. 콤보는 영구 측면 통계로 남기지 않고 연속 회피에 성공한 순간 키보드 바깥 상단 HUD의 우측 진행도 칸에 잠시 나타나 키 캡과 공격을 가리지 않으며, 최고 콤보는 결과 화면에 표시됩니다.

## 로컬 기록과 런 보고서

STAGE 01~06은 기록과 관계없이 처음부터 모두 선택할 수 있습니다. 각 카드에는 이 브라우저에서 쌓인 시도·클리어와 최고 등급 또는 최고 도달 웨이브가 표시됩니다. 최고 점수, 최고 콤보, 클리어 최고 잔여 HP와 최고 레이팅도 스테이지별로 따로 보존됩니다.

클리어 또는 게임 오버 뒤에는 `RUN GRADE`, 0–100 레이팅, 점수, 최고 콤보, 남은 HP와 도달/전체 웨이브를 한 보고서에서 확인합니다. 첫 클리어, 최고 등급, 최고 점수, 최고 콤보, 최고 HP 또는 최장 도달 기록을 갱신하면 해당 배지가 함께 표시됩니다. 결과는 고유 런 ID가 있는 중앙 종료 경로에서 한 번만 집계되므로 RETRY, NEXT STAGE나 STAGE SELECT가 같은 런을 중복 저장하지 않습니다.

기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 계정, 서버, 클라우드 동기화와 온라인 순위표는 없으며 저장 데이터가 없거나 손상돼도 빈 기록으로 안전하게 시작합니다.

활성 존은 5웨이브 펄스마다 자주 변합니다. 축소할 때는 직전 공격에서 위험했던 키만 붕괴 후보가 되며, `COLLAPSE WARNING`으로 1.5박 피할 시간을 준 뒤 사라집니다. 경고가 끝날 때도 그 셀에 남아 있으면 일반 피격과 같은 500ms 무적 규칙으로 피해 1을 판정하고, 피해 차단 여부와 관계없이 남은 키 중 물리적으로 가장 가까운 활성 키로 밀려납니다. 확장 키는 `RESTORE WARNING`으로 1.25박 먼저 보여준 뒤 활성화됩니다. 전환 경고 중에는 다음 공격이 진행되지 않습니다.

| 스테이지 | 선택 키 | 웨이브 | 예상 길이 | 오프닝 BPM | BPM 범위 | 활성 키 범위 |
|---|---:|---:|---:|---:|---:|---:|
| STAGE 01 | Q | 52 | 약 115.2초 | 92 | 82–110 | 5–11 |
| STAGE 02 | W | 56 | 약 114.9초 | 100 | 88–122 | 8–15 |
| STAGE 03 | E | 60 | 약 113.7초 | 108 | 94–132 | 10–19 |
| STAGE 04 | R | 64 | 약 113.4초 | 116 | 102–142 | 12–22 |
| STAGE 05 | T | 68 | 약 114.5초 | 124 | 108–150 | 15–25 |
| STAGE 06 | Y | 72 | 약 114.0초 | 132 | 116–156 | 18–26 |

결과 화면의 `RETRY`는 같은 스테이지의 오프닝 BPM 카운트다운을 시작하고, `STAGE SELECT`는 무선택 선택 화면으로 돌아갑니다. `NEXT STAGE`는 STAGE 01~05를 클리어했을 때만 표시되며 다음 스테이지의 카운트다운을 시작합니다. 이때 `Space`/`Enter`의 기본 동작은 NEXT STAGE이며, 게임 오버 또는 STAGE 06 클리어에서는 RETRY가 기본 동작입니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm 11이 필요합니다.

```bash
pnpm install
pnpm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.
